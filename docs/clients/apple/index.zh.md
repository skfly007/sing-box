# sing-box for Apple platforms

SFI(sing-box for iOS)/SFM(sing-box for macOS)/SFT(sing-box for tvOS) 允许用户管理并运行本地或远程的 sing-box 配置文件，并提供平台特定的功能实现，例如 TUN 透明代理的实现。

!!! failure ""

    由于非技术原因，我们暂时无法在 App Store 上更新 sing-box 应用，也无法发布 macOS 客户端的独立版本（TestFlight 用户不受影响）。

## :material-graph: Requirements

* iOS 15.0+ / macOS 13.0+ / Apple tvOS 17.0+
* An Apple account outside of mainland China
